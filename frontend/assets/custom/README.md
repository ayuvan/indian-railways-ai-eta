# Custom Rolling Stock & Station Media Directory

Drop your custom images or 3D renders here for automatic detection by the Indian Railways Dynamic AI ETA Prototype:

- **`loco_3d.png`** or **`loco_3d.webp`**: 3D rendered locomotive or trainset (shown on the Passenger Boarding Pass & Control Room radar).
- **`station_hero.jpg`**: High-resolution photo of the current or destination station.
- **`cabin_view.jpg`**: First-person loco cab or passenger coach interior view.

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`.
The web application includes automatic fallback to the built-in high-definition vector assets (`wap7_locomotive.svg`, `vande_bharat.svg`, `wag9_freight.svg`) if no custom media is found.
